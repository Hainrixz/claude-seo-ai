# static

**Status:** stable · **Last verified:** 2026-09-05 · **Detector id:** `static` · **Layer:** framework

Hand-written or exported HTML with no build system. The simplest, most reliable write path in the
whole set: the file you edit is the file that is served.

## 1. Detection recap

`static` is a claim about **absence**: a root `index.html` (3), second-level `*/index.html` (2), and
`assets|css|js|img|images|styles/` directories (2), with **no** build config anywhere in the project.
The verdict is dropped the moment any framework signal or build config file appears. Without
`--path`, an unrecognised site simply has no framework — not `static`.

## 2. Generated automatically — do not re-add

Nothing at all. Every tag in the head was put there by a person, and every tag that is missing is
genuinely missing.

## 3. URL surfaces & duplicate risks

| Surface | Shape | Risk |
|---|---|---|
| Directory index | `/about/` served from `about/index.html` | — |
| Explicit file | `/about.html` | Both variants answering 200 is a duplicate |
| Index equivalence | `/`, `/index.html` | Duplicate unless one redirects |
| Case | `/About/` vs `/about/` | Case-sensitive origins serve both |
| Missing trailing slash | `/about` vs `/about/` | Host-dependent; check the redirect |

## 4. Platform-owned — do not fix

Nothing. The host may own the redirect and 404 behaviour (Netlify `_redirects`, Cloudflare Pages,
Apache `.htaccess`, nginx config) — name the host as the owner for those, not the site.

## 5. Fix map

| Class | Location | Adapter | Class | live_impact |
|---|---|---|---|---|
| Title, description, canonical, OG, `<html lang>` | the page's `<head>`, inserted after `<meta charset>` / `<title>` | `local-files` | AUTO (`html-head`) | none |
| JSON-LD | a `<script type="application/ld+json">` in the head | `local-files` | AUTO | none |
| robots.txt | `<root>/robots.txt` (created when absent) | `local-files` | AUTO | none |
| sitemap.xml | `<root>/sitemap.xml` (created from the crawl) | `local-files` | AUTO | none |
| Redirects | the host's own config (`_redirects`, `.htaccess`, …) | `instructions` | ADVISORY | none |
| Image alt | the `<img>` tag itself | `local-files` | AUTO | none |

Route mapping is direct: `/<path>/` → `<root>/<path>/index.html`, `/<path>` → `<root>/<path>.html`.

## 6. Write method & credentials

`local-files`, no credentials. Without `--project` there is no write path at all — the profile
offers `instructions`, and the fix is the exact snippet plus the file it belongs in.

## 7. Preview & publish

Repo edits; whatever the user deploys with publishes them.

## 8. Verification

Source-level (the file now contains the tag), then a re-snapshot of the live URL when the user says
they deployed. Static hosts and CDNs cache hard: `pending_cache` until the public HTML agrees.

## 9. Rollback

Restore the file from `before/`. Files this run created (`robots.txt`, `sitemap.xml`) are removed
rather than restored, and the manifest records which ones were created.

## 10. Check ids

No static-specific ids: every generic module id applies, and nothing is suppressed — this is the one
platform where "the site owns everything" is literally true.
`M2.hosting.preview_environment_audited` (warn · 1 · advisory) still fires when the audited host is a
preview or staging environment.

## 11. Manual paths (EN / ES)

- EN: paste the snippet into `<head>`, right after the `<title>` tag, then redeploy.
  ES: pega el fragmento en `<head>`, justo después de la etiqueta `<title>`, y vuelve a desplegar.
- EN: `robots.txt` and `sitemap.xml` go in the site root, next to `index.html`.
  ES: `robots.txt` y `sitemap.xml` van en la raíz del sitio, junto a `index.html`.

## 12. Honesty & UNVERIFIED

- A hand-written site may be generated by something we cannot see (an exporter, a desktop tool).
  If the HTML shows an exporter's fingerprint, say so and treat file edits as PROPOSED — the next
  export will overwrite them.
